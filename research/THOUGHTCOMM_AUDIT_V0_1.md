# ThoughtComm source audit v0.1

**Date:** 2026-09-29
**Paper:** Zheng et al., [*Thought Communication in Multiagent Collaboration*](https://arxiv.org/abs/2510.20733), NeurIPS 2025 Spotlight. The audit uses the paper's arXiv HTML v1 and official NeurIPS proceedings PDF.
**Scope:** paper and public-repository discovery only. No model weights, datasets, or third-party implementations were downloaded or run.

## Why this is a serious comparator

ThoughtComm models observed agent states as generated by latent variables, aims to recover thought dimensions shared or private to agents, and identifies which agents depend on each dimension. It uses a sparsity-regularized autoencoder to extract these dimensions and a learned prefix adapter to condition each agent's next generation. The paper proves identifiability results (up to relabeling) for shared/private dimensions and the thought-agent dependency pattern under its assumptions.

This is more than a new message syntax: it proposes latent semantic factorization, recipient-specific routing, and receiver-side integration, with theory aimed at the shared/private distinction. Its key conceptual contribution is therefore a relevant upper-bound baseline for *structured latent communication*.

## What the theory establishes, and what it does not

The setup assumes observed states are generated by an information-preserving, invertible, twice-differentiable function of latent thoughts, with sufficient variation for Jacobian support conditions. The identifiability theorem is stated for an L0-sparse Jacobian model; the practical autoencoder objective uses an L1 Jacobian penalty as a surrogate. Under the formal assumptions, recovered latent coordinates and their shared/private dependency pattern are identifiable up to permutation.

That theorem is not an unconditional guarantee that each learned coordinate corresponds to a human-named or task-grounded semantic thought, that finite-sample autoencoder training recovers it, that a receiver causally uses the transmitted information, or that the channel is communication-efficient. The empirical synthetic experiment uses data generated by a random invertible transformation, directly matching the assumed data-generating family. The synthetic result validates recovery in that controlled family, not by itself in arbitrary LLM hidden states.

## Experimental scope

- The real-world experiments use three agents and two debate rounds on MATH and GSM8K, evaluate five models from Qwen3-0.6B to Llama-3-8B / DeepSeek-R1-Distill-Llama-8B, and compare against single-answer and Multiagent Finetuning. The paper explicitly says it does not exhaustively compare collaboration workflows.
- It reports 500 examples to fine-tune the latent communication module and 500 held-out evaluation examples. The main experiments use one prefix vector/token. The appendix says experiments ran on one node with eight NVIDIA H100 GPUs.
- Reported accuracy is strong in the tested conditions (for example, Qwen3-1.7B MATH: 93.0% ThoughtComm vs 75.8% Multiagent Finetuning). These are reported paper results, not results reproduced in Tacit.
- Agents debate the same benchmark problem. Their different hidden states can encode divergent reasoning, but the setup is not a complementary-private-evidence task where the receiver lacks a crucial fact and only the sender observes it. Accordingly it supports collaborative reasoning with latent state, not yet transfer of necessary private evidence.
- The method collects each agent's last-token final-layer state for a response contextualized by its text, concatenates states for a shared autoencoder, then routes/reweights latent dimensions and injects a learned prefix. It is a trained latent-state collaboration method, not a standalone language usable by arbitrary agents.

## Cost and portability boundaries

The paper reports accuracy, consensus, debate-round scaling, and prefix-length ablations, but no serialized payload-byte, inter-process transport, network latency, or complete communication-plus-inference cost frontier. A one-token prefix is an interface shape at the receiver, not the number of values or bytes that had to cross between agents. For a portable implementation, count the communicated latent coordinates and dtype, metadata/framing, encoder/adapter transfer and storage, extraction/encoding and receiver-conditioning compute, both agents' inference, and training/setup amortization. Separate local shared-process tensor access from serialized cross-process communication.

The paper does not include an official implementation link on its arXiv landing page. Public GitHub results include third-party reproductions, which must not be mistaken for author code or replication evidence. A reproduction should pin and audit one independently before use.

## Falsifiable Tacit follow-ups

1. On a receiver-need task with disjoint private records, test whether the latent message transfers the sender-only fact. Include true message, same-shape message from another episode, zero/neutral message, and no-message controls; verify receiver capacity without the sender.
2. Compare against equal-budget optimized natural language, compressed text, structured tuples/JSON, and a learned dictionary under the same agent schedule. Sweep serialized bytes and report task success, semantic fidelity, latency, compute, robustness, and setup amortization.
3. Ablate the shared/private structure mask against unstructured pooling and shuffled agent masks. If recipient-specific latent routing is the mechanism, correct routing should outperform equal-capacity shuffled routing on tasks where recipient information needs differ.
4. Measure scaling by evidence cardinality, agent count, rounds, and byte budget. A one-prefix interface or high consensus is not evidence of improved communication complexity or task utility.

## Project decision

Include ThoughtComm in the conditional latent baseline family when model internals and training resources are available. Keep its theorem, benchmark performance, and channel-efficiency claims separate: the first is assumption-bounded identifiability; the second is a reported same-problem debate result; the third remains unmeasured in the paper. Do not attempt local reproduction while the project's frozen host-resource gate blocks model runs.
